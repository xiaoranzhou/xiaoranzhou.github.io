DataPLAN

LLM-Powered Data Management Plan Generator for Plant Sciences

DataPLAN leverages large language models to automatically generate comprehensive, compliant data management plans. The tool integrates LLM workflows to understand research contexts, suggest appropriate metadata standards, and create structured DMPs that meet funder requirements.

LLM Integration Workflow Automation ISA Framework Research Data Management

elab2arc

AI-Driven Conversion of Experimental Protocols to Standardized Formats

elab2arc uses advanced natural language processing and LLMs to automatically parse free-text experimental protocols from electronic lab notebooks and convert them into standardized, machine-readable Excel files compliant with ARC (Annotated Research Context) specifications.

NLP LLM Parsing ARC Specification Data Standardization
GitHub Repository

DataPLAN MCP Server

Model Context Protocol Server for Research Data Management

A custom-built MCP (Model Context Protocol) server that enables AI assistants like Claude to directly interact with DataPLAN functionality. This server provides structured access to data management planning capabilities, allowing seamless integration of DMP generation into AI-powered research workflows.
