# Website Color Palette
**Inspired by Plant Root Simulation Animation**

## Nature-Inspired Color System

This palette is designed to match the earthy, organic aesthetic of the plant root simulation GIF (animation.gif).

### Primary Colors

**Deep Forest Green** `#2d4a3e`
- Usage: Primary color, navbar text, headings, primary buttons
- Represents: Plant growth, nature, stability
- Used in: Navigation, Publication section, AI Tools section, GitHub section

**Sage Green** `#5a7c70`
- Usage: Secondary color, accents, hover states
- Represents: Fresh growth, new shoots
- Used in: Gradients, hover effects, links

**Soft Moss** `#8b9d83`
- Usage: Accent color, lighter gradients
- Represents: Natural vegetation, calm
- Used in: Skills section, lighter gradient ends

### Earth Tones

**Soil Brown** `#6b5744`
- Usage: Earth elements, tool card borders
- Represents: Rich soil, foundation
- Used in: Expertise section, tool card borders

**Root Beige** `#c9b896`
- Usage: Light accents, warm highlights
- Represents: Plant roots, natural fiber
- Used in: Skills section gradient, card accents

**Dark Soil** `#1a2b26`
- Usage: Dark backgrounds, footer
- Represents: Deep earth, stability
- Used in: Contact section background

## Color Application Map

### Sections

1. **Hero Section**: Uses animation.gif background
2. **Publications Header**: Forest green → Sage green gradient
3. **AI Tools**: Forest green → Sage green gradient
4. **Expertise**: Soil brown → Soft moss gradient
5. **Skills**: Soft moss → Root beige gradient
6. **GitHub**: Forest green → Soil brown gradient
7. **Contact**: Dark soil → Forest green gradient

### UI Elements

**Navigation Bar**
- Background: White with slight transparency
- Text: Deep forest green
- Hover: Light sage green background

**Buttons**
- Primary: Deep forest green
- Primary Hover: Sage green
- Outline: Forest green border

**Cards**
- Tool Cards: White with soil brown left border
- Expertise Cards: Various green/brown gradients
- GitHub Cards: White with subtle shadows

**Skill Tags**
- Default: White background, forest green text
- Hover: Forest green background, white text

---

## Design Philosophy

The color palette creates a cohesive, nature-inspired aesthetic that:
- **Complements** the plant simulation GIF
- **Evokes** growth, research, and natural processes
- **Maintains** professional readability
- **Provides** visual hierarchy through earth tone variations
- **Reduces** color complexity from 10+ colors to 6 harmonious tones

---

## Accessibility

All color combinations maintain WCAG AA contrast ratios:
- White text on all gradients: ✅ Pass
- Dark green on white: ✅ Pass
- Hover states: ✅ Pass
